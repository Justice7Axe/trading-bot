# 백테스트 프로토콜 (Claude Code 가 따라야 할 절차)

## 0. 원칙
1. **룩어헤드 금지**: i 번째 바 종가까지의 정보로만 신호. 진입은 i+1 바 시가. 피벗은 우측 바가 지나야 확정. `Day.daily`(당일 일봉)는 전략에서 쓰지 않는다.
2. **비용 포함**: 수수료 + 거래세 + 슬리피지. 비용 0 결과는 보고하지 않는다.
3. **보수적 체결**: 같은 바 손절·목표 동시 도달 시 손절 우선, 갭 손절은 시가 체결, 지정가 목표는 1틱 이상 통과해야 체결, VI 단일가 구간 체결 금지, 상한가 매수 불가.
4. **표본 분리를 먼저 정한다**: 데이터를 보기 전에 in-sample(IS)/out-of-sample(OOS) 경계를 정하고 기록. 파라미터는 IS 에서만 조정, OOS 는 최종 1회만 본다.
5. **생존편향 제거**: 상장폐지·관리종목·거래정지 종목 포함, 수정주가 사용(액면분할·증자). 유니버스는 '그 날짜 기준'으로 구성.
6. **[S] 규칙은 바꾸지 말고 [A] 파라미터만 튜닝**. [S] 규칙을 바꿔야 결과가 나온다면 그건 '그 트레이더의 기법'이 아니라 새 전략이다. 리포트에 명시.

## 1. 데이터
CSV 형식은 `scripts/data.py` 상단 주석 참고. 최소: datetime, symbol, OHLCV (1분봉).
- 한국 주식 1분봉 후보 (제공 기간·조회 한도는 각 API 문서에서 확인): 한국투자증권 KIS Open API(분봉 조회), 키움 OpenAPI/REST, 대신증권 CYBOS Plus, 유료 벤더(코스콤 등). 일봉은 pykrx 등.
- 재료(catalyst) 플래그: DART 공시 시각, 뉴스 시각을 종목·분 단위로 매핑해 `catalyst` 컬럼(그 시각 이후 1)으로 넣는다. 없으면 S1 은 가격·거래량 근사만으로 돌아간다(리포트에 명시).
- VI 플래그: 가능하면 KRX VI 발동 내역을 `vi` 컬럼으로. 없으면 정적 VI 근사.
- 선물: NQ/MNQ 1분봉(ET), 가능하면 buy/sell volume. 코스피200 선물 1분봉(KST). 연결선물(롤오버) 방식 기록.
- 바 라벨이 '종료 시각'인 데이터(예: 09:01 = 첫 1분)는 `--label end`.

## 2. 실행 순서
```
python scripts/selftest.py [작업폴더]                 # 엔진 불변조건 확인 (코드 수정 후 매번)
python scripts/run_backtest.py --strategy <name> --instrument <INST> --data "<csv glob>" --out results/<name>_base --split <IS 종료일>
python scripts/run_backtest.py ... --split <IS 종료일> --grid key=v1,v2,v3 --grid key2=...   # IS 에서만
python scripts/run_backtest.py ... --set key=value --split <IS 종료일>                      # 고른 값으로 IS+OOS 1회
```
- 기본값(baseline) 결과를 반드시 먼저 남긴다.
- 그리드는 한 번에 2~3개 파라미터, 각 3~5개 값. "최고점"이 아니라 "주변 값도 비슷하게 좋은 평평한 구간"을 고른다.
- 비용 민감도: `--slippage 2`, `--slippage 3` 으로 다시 돌려도 기대값이 양수인지. 수수료는 `--fee-rate` 로 사용자 값 반영.
- 워크포워드(선택): 12개월 IS / 3개월 OOS 를 굴려가며 반복, OOS 구간만 이어붙여 평가.

## 3. 합격 기준 (기본값 `engine.DEFAULT_CRITERIA`, 사용자와 합의해 바꿀 수 있음)
- OOS 트레이드 ≥ 200 (S2 처럼 희소한 전략은 전체 유니버스로 늘리거나 기준을 명시적으로 낮춤)
- OOS 기대값 ≥ +0.10R (비용 차감 후), Profit Factor ≥ 1.2
- 최대낙폭 ≤ 15% (리스크 0.5% 기준)
- 상위 5개 트레이드 제외해도 순이익 > 0
- 연도별로 한 해에만 몰린 수익이 아닐 것 (`by_year`)
- 슬리피지 2틱에서도 기대값 > 0

## 4. 리포트 (results/<run>/report.md 에 아래를 덧붙여 사용자에게 보고)
1. 한 줄 결론: 합격/불합격, OOS 기대값(R)과 PF.
2. 데이터: 기간, 종목 수, 출처, catalyst/VI/buy-sell 데이터 유무.
3. 규칙: 바꾼 [A] 파라미터와 이유. [S] 규칙 변경 여부.
4. 결과 표: IS vs OOS, 비용 민감도, 등급/모델/패턴별 분해.
5. 위험: 최대 연속 손실, 최대낙폭, 상위 5개 의존도.
6. 다음 단계: 불합격 원인 가설 1~3개, 또는 합격 시 모의투자 계획(최소 1~3개월, 실전과 같은 수량 규칙).

## 5. 하지 말 것
- OOS 결과를 보고 파라미터를 다시 고르기 (그 순간 OOS 는 IS 가 된다)
- 합성 데이터(`make_sample_data.py`) 결과를 수익성 근거로 쓰기
- 승률만 보고 판단하기 (S3 같은 추세형은 승률 30%대가 정상일 수 있다. 기대값 R 이 기준)
- 대회 수익률을 재현 목표로 삼기
