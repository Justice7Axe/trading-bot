# 한국 주식 단타 전략 명세 (Breitstein 메인 + 丁伟锋 시간/패턴 규칙)

공통 전제
- 롱 전용 (개인 공매도 제약). Breitstein 의 과열 숏(euphoria fade)은 주식 모듈에서 제외 -> 지수선물/인버스로만 별도 검토.
- 1분봉, KRX 연속매매 09:00~15:20 (15:20~15:30 종가단일가 제외), 데이트레이딩: 15:15 전량 청산 [A].
- **시간 규칙 [S, 丁伟锋]**: 09:00~09:15 신규 진입 금지, 15:05 이후 신규 진입 금지.
- **리스크 [S/A]**: 트레이드당 계좌 0.5% (Fabio 0.25~0.5% 범위, 丁伟锋 3% 상한 내 보수적 선택), 하루 3패면 중단 [S, Fabio], 일 손실 1.5% 중단 [A], 동시 3포지션 [A].
- 코드: `scripts/strategies.py` 의 클래스. 파라미터 이름은 아래 표와 같다.

## KR-S1 재료주 VWAP 추세 눌림 (`kr_s1_inplay_vwap_pullback`) — Breitstein 메인

| 단계 | 규칙 | 근거 | 파라미터(기본) |
|---|---|---|---|
| 종목 | 재료로 움직이는 in-play 종목만 | [S] | `require_catalyst`(False, catalyst 데이터 있으면 True) |
| in-play 근사 | 전일 대비 +5% 이상, 같은 시각 누적거래량 20일 평균의 3배 이상, (선택) 누적 거래대금 하한 | [A] | `min_change_pct`5, `min_rvol`3, `min_value`0 |
| 추세 | 최근 30분 종가의 80% 이상이 VWAP 위, VWAP 상승 | [S] VWAP 위 '꾸준히' / 숫자 [A] | `lookback`30, `above_ratio`0.8 |
| 눌림 | 최근 5봉 저가가 VWAP+0.5ATR 이내로 접근, 종가는 VWAP-0.3ATR 아래로 안 감 | [A] | `pullback_bars`, `pullback_atr`, `vwap_buffer_atr` |
| 트리거 | 양봉 + 직전 봉 고가 돌파 종가 + VWAP 위 -> 다음 봉 시가 진입 | [A] | - |
| 손절 | 눌림 구간 최저가 - 1틱, 손절폭 3% 초과 시 패스 | [A] | `max_stop_pct`3 |
| 청산 | 2R 에서 50% 익절 후 본절 이동 / VWAP 아래 2봉 연속 종가 시 전량 / 15:15 | [S] VWAP 이탈 시 롱 불가 / 숫자 [A] | `target_r`, `exit_closes_below_vwap`2 |
| 등급 | 가점 4개(재료, RVOL≥5, 등락률≥10%, 일봉 20일선 위) -> A(3+)/B(2)/C(1)/D(0, 매매 안 함), 비중 1.0/0.5/0.25/0 | [S] 등급별 비중 차등, 다중 시간대 정렬 / 배점 [A] | `grade_*` |
| 가격제한 | 진입가가 상한가 이상이면 체결 불가로 보고 패스 | [A] 보수적 | - |

검증 포인트: 등급별 평균 R 이 A > B > C 순서로 나오는지 (`by_grade_avgR`). 순서가 안 맞으면 등급 규칙이 엣지를 못 잡는 것.

## KR-S2 투매 후 V자 오른쪽 반등 (`kr_s2_capitulation_reversal`) — Breitstein capitulation

| 단계 | 규칙 | 근거 | 파라미터 |
|---|---|---|---|
| 일봉 셋업 | 직전 3일 연속 각 -4% 이하 하락 + 각 일 거래량 ≥ 20일 평균 1.5배 + 3일 누적 -15% 이하 | [S] A·B·C 3일 대량 급변 / 숫자 [A] | `n_days`3, `min_daily_drop_pct`4, `vol_mult`1.5, `min_cum_drop_pct`15 |
| D일 | 시가 갭 -3% 이하 + 같은 시각 RVOL ≥ 2 | [S] D일 더 큰 거래량의 갭 / 숫자 [A] | `min_gap_down_pct`3, `min_rvol`2 |
| 투매 확인 | 당일 저점 ±2봉 내 1분 거래량 ≥ 당일 평균 3배 | [A] | `climax_mult`3 |
| 진입 | 저점 후 2~30봉 사이, 저점 이후 최고가를 종가로 돌파(V자 오른쪽) -> 다음 봉 시가 | [S] 반전 확인 후 진입 / 숫자 [A] | `min_bars_after_low`, `max_bars_after_low` |
| 시간 | 09:15~11:30 | [S] 15분 규칙 / 11:30 [A] | `entry_start`, `entry_end` |
| 손절 | 당일 저가 - 1틱 (손절폭 6% 초과 패스) | [A] | `max_stop_pct`6 |
| 청산 | 1.5R 에서 50%, 본절 이동, 나머지 3ATR 트레일링, 15:15 | [A] | `target_r`, `trail_atr` |

주의: 표본이 적다(연 수~수십 건). 종목 수를 크게(코스피+코스닥 전체) 해야 의미 있는 통계가 나온다. 상장폐지·거래정지 종목을 포함한 생존편향 없는 유니버스 필수.

## 결합 실전 체크리스트 (백테스트 통과 후 모의/소액 검증용)
1. 09:00~09:15: 관찰만. 등락률·거래대금 상위, 재료 확인, 첫 5분 고가 기록.
2. 종목 등급 매기기 (S1 가점표). D 등급은 보지 않는다.
3. 진입 조건: 개장 5분 고가 위 + VWAP 위 꾸준히 + (S1 눌림 트리거 또는 S3 패턴 완성).
4. 손절가 먼저 정하고, 수량 = 계좌×0.5%×등급배수 ÷ (진입-손절). `scripts/engine.py` run_portfolio 와 같은 식.
5. VWAP 아래 2봉 종가 / 반대 패턴 / 클라이맥스 거래량 -> 청산.
6. 하루 3패 또는 -1.5% 면 종료. 15:05 이후 신규 금지, 15:15 전량 정리.
7. 투매일(S2 조건)은 별도 감시: 저점 확인 후 V자 오른쪽에서만.
