# 📍 중심선 기법

공통 백테스트 원칙은 `backtest-rules` 스킬을 따른다.

## 0. 지금 상태 (2026-10-30)
- **모의 매매만** (사용자 10-30 '모의 매매로 해줘'). 실전은 안 함. 전용 몫 300만·종목당 50만, 보유 한도 10칸은 안 씀, 몫을 넘으면 잔고 밖 가상(🟣).
- 코드: 실시간 `kiwoom_trading/strategies/centerline/live.py` (`CenterlineWatcher`, `load_picks`, `exit_reasons`) → `execution/paper.py` mode `'중심선'`, 스캐너 `screener/run_intraday.py`.
- ⚠️ 1년 계좌 시험에서는 보탬이 거의 없었다(아래 4장). 모의로 실제 체결·손익을 쌓아 보고 판단한다.

## 1. 규칙
| 단계 | 내용 |
|---|---|
| 기준봉 | 양봉, 전날 대비 +10%↑, 거래량 ≥ 직전 20일 평균 × 3, 대금 ≥ 100억, **그날 주식 대금 20위 안**, **대금 ≥ 직전 20일 평균 대금 × 10**, 우선주 제외 (순위·대금·거래량은 daily_ohlcv 통합 값) |
| 중심선 | 기준봉 정규장 (시가 + 종가) / 2. 실시간은 KRX 1분봉 09:00~15:30 으로 정규장 값을 만든다 (9-14 부터 일봉 종가 = 애프터 종가) |
| 대기 | 기준봉 뒤 10거래일 안. 그 사이 시가가 중심선 아래거나 종가가 중심선 아래로 마감하면 끝. 이미 한 번 닿은 날이 있으면 그날 산 것으로 보고 후보에서 뺌 |
| 매수 | 오늘 시가가 중심선 아래면 안 삼. 장중 저가가 중심선에 닿으면 매수 (백테스트는 중심선 지정가, 모의는 닿은 순간 시장가 — 중심선 +1% 넘게 이미 반등했으면 추격 안 함) |
| 하락장 | 09:10 강한 하락장 판정 뒤에는 안 삼. 그 전 체결은 삼 |
| 매도 | 장중 중심선 × 0.97 닿으면 손절 · 종가가 중심선 아래면 다음 날 09:00 · 산 날 포함 5거래일 들고 6일째 09:00. 익절 없음, 15:19 에 안 팖 |
