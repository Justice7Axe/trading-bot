## 1. 큰 원칙 (프롤로그·1장)
- 단타 = 당일 매수·매도. **집중 시간은 09:00~10:00 딱 1시간**, 그다음은 본업 (9·149쪽). 하루 목표 10만~100만 원, 컨디션·시장이 나쁘면 쉰다 (6쪽).
- **100만 원으로 시작, 200만 원 만들 때까지 추가 입금 금지**, 다 잃으면 그만둔다 (7·37·41쪽). 단타 전용 계좌를 따로 둔다 (40쪽).
- 월간 목표 = 하루 목표 × 거래일 수, 주간·월간 복기 (42쪽). **수익금은 반드시 인출** — 복리는 이상, 인출은 현실 (43~44쪽). 리밸런싱(수익 덜어내기)이 롱런의 비결 (45~51쪽).
- 매매 전 선언 3가지: "손절점에서 무조건 손절", "**2번 연속 손절이 나오면 매매하지 않음**", "수익금 즉시 인출" (142쪽).
- 소액이 유리: 시총 100억~5,000억 소형주도 호가 부담 없이 매매 (36~37쪽). 한국 주식은 장기 보유가 위험하고(코스피 ÷ M2 는 30년 박스권) 공시 위험이 있다 → 단타 또는 한 달 안 스윙 (25~30쪽).
- 보조지표는 이평선만(막시무스 예외). 이평선 **4·15·20·120** (일봉·분봉 같은 숫자), 거래량은 '전날보다 많으면 양봉' 색으로 (85~87쪽).
- 차트 볼 수 없으면 그날 매매하지 않는다. 30분 이상 자리를 비우면 정리 (166·213쪽). 단타에서 자동 매수는 쓰지 않는다 (213쪽).

## 2. 캔들·거래량·지지저항 (1장 52~78쪽)
| 상황 | 책의 해석 |
|---|---|
| 바닥권 + 거래량 장대양봉 | 추세 전환 신호, 모든 매매의 시작 (57·71쪽). 다음 날 양봉·거래량 유지 확인 |
| 고가권 + 거래량 장대음봉 | 탈출 신호 (59쪽) |
| 바닥권 + 거래량 장대음봉 | 마지막 투매, 바닥 다지기 (59쪽) |
| 상승 중 + 거래량 작은 음봉 | 눌림 = 매수 기회 (72쪽) |
| 윗꼬리 긴 양봉 + 거래량 폭증 / 연속 급등 끝 최대 거래량 양봉 | 물량 넘김 경고 (73쪽) |
| 갭 상승 양봉인데 거래량 감소 | 다음 날 갭 메우며 빠지는 경우 많음 (73쪽) |
| 단기 고점 반복 윗꼬리 | 매물 소화 중, 다 소화되면 돌파 (60~61쪽) |
- **외워야 할 문장 (87쪽)**: "거래량이 터진 양봉 → 거래량이 줄면서 눌림(소폭 하락·횡보) → 그 자리에서 지지가 확인되면 매수."
- 거래량 = 관심, 거래대금 = 큰돈. 세력이 왔는지는 **거래대금**으로 (66~67쪽). 상·하한가 거래량, 급등 끝 거래량, 뉴스 한 방 거래량은 믿지 말 것 (68쪽).
- 지지 = 바닥(반등이 반복된 자리, 가격이 아니라 구간), 저항 = 천장(물린 사람의 본전 매도). **지지 깨지면 저항, 저항 뚫으면 지지** (75~78쪽).
- 지지 부근 **분할 매수**, 저항 부근 **분할 매도 — "모르면 반만 판다"** (76~78쪽).

## 3. 장전 준비 (2장)
- **장전 종목 3~5개**를 미리 고른다. 장중에 찾으면서 매매하지 않는다 (117쪽).
- **전날 마감 기준 거래대금 100억 원↑ + 거래량 1,000만 주↑** (117~119쪽). 거래량만 보면 동전주가 올라오니 반드시 거래대금으로.
- 시간외 단일가 순위는 더 이상 안 본다 (NXT 뒤 의미 없음, 시간외 급등은 다음 날 갭 뒤 하락) (119쪽).
- 제외: 관리종목·투자위험·투자경고·거래정지·투자경고예고·정리매매·단기과열·ETF·우선주·자본잠식 (120쪽).
- **테마 파악**: 거래대금 상위 20~30 → 같은 업종·이슈 → **3종목↑ 같은 테마면 주도 테마** → 뉴스로 이유 확인 (123쪽). 주도 테마가 안 보이는 날은 쉰다 (123쪽).
- 하락장(지수가 이전 저점을 깸): 강한 테마 종목만, 개별 재료 종목은 안 건드림. 하락장에 오르는 테마 = 정치 인물주·금리(고배당 은행)·전쟁(스페코·빅텍)·원자재·질병 (125~126쪽).
- **쌍쌍바 매매법** (127~136쪽): 섹터 대장주(그 테마 **상승률 1위** — 거래대금 아님, 내릴 때도 가장 많이 내림)가 오르면 2등주가 뒤따른다.
  1) 평소 테마별 대장·2등을 정리(예: 천연가스 지에스이/중앙에너비스, 시멘트 고려시멘트/삼표시멘트, 방송 YTN/한국경제TV)
  2) 장중 대장 **+5%↑ · 거래량 급증 · 호재 뉴스** 확인 3) **즉시 2등주 매수** (대장 +5% 때 2등은 아직 +1~2%) — 속도가 생명.
  사례: 삼표시멘트 +3% 진입 → 최고 +9% → +7% 익절 (133쪽). 2등이 불분명하거나 대장만 오르거나 테마가 약하면 쓰지 않는다 (135쪽).
- 모닝 루틴: 미국 3대 지수(나스닥 1순위), 관심 종목 뉴스·공시 재확인, 배터리·인터넷·MTS 미리 접속, 08:00 NXT 보유 종목 확인, **08:57~08:59 동시호가 예상가** 확인 (139~144쪽).

## 4. 09:00~10:00 집중 매매 (3장)
- 09~10시가 거래량 최대 (코스피 10분봉), 점심 최저, 장 막판 다시 증가 (149쪽).
- 장 시작 직후 오르는 종목 **추격 매수 금지**. 주도 테마가 명확할 때만 시작 (150쪽).
- 지수 차트를 계속 본다. 종목이 갑자기 빠지면 지수 탓인지 확인 (150~151쪽).
- **상승장**(지수 +1%↑ 날): 가장 강한 주도 섹터·테마의 **대장주** 위주, 분할 매수 (153쪽). 초보는 상승장엔 스윙이 더 나을 수도 (152쪽).
- **하락·횡보장**: 단기 돈이 몰리는 가벼운 '사이드 테마'(저출산·정치·가덕도·돼지열병 등)의 대장주. 무거운 메인 섹터(반도체·조선·2차전지 등)는 피함. 기준에 맞는 종목 없으면 안 함 (153~154쪽).
- **10시 이후**: 리스크 관리가 우선. **2차 상승** = 9~10시 급등 종목 중 거래량 유지하며 옆걸음, 5·10분봉 저점을 깨지 않고 다시 오르는 종목 (160~161쪽). 10시 이후 재진입은 고점·저점이 이미 있어 손절선 잡기 쉬움. 거래량 줄며 옆걸음이면 매매 자제, 14시 이후 거래량 다시 증가 (161~162쪽).
- 자동 주문: **+1% 전량 익절 호가 주문, −2% 자동 손절** (162~167쪽). 1% 는 거래량 준 시간대의 현실적 수익 폭, −2% 는 감당 가능한 마지노선. 등락률 5%↑ 알람.
- 점심(12~13시)은 새로 사지 않음 (164~165쪽).

## 6. 매도·손절 (5장)
- **123 매도법** (230쪽): '줄 때 챙긴다'. +1% 땡큐·+2% 감사·+3% 아멘에 기계적으로 나눠 판다. 입문자 권장.
