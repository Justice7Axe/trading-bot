# 백테스트 공통 원칙 (D:\Ellie\trading)

매매법별 스킬은 규칙·결과만 적고, 이 문서의 공통 원칙을 따른다 (docs/architecture.md).

## 2. 자료 함정 (어기면 결과가 부풀거나 줄어든다)
- **일봉은 수정주가, 1분봉은 받은 날 가격.** 같은 날 값이 다를 수 있다 → 가격 레벨을 섞을 땐 엔진의 `factor`(1분봉 종가 ÷ 일봉 종가)로 맞춘다.
- **2026-09-14 부터 일봉 종가 = 20:00 애프터 종가.** 정규장 값은 1분봉 15:30 에서만. 엔진 `daily_day` 가 보정한다. 장중 판단은 정규장 값으로.
- **그날 대금 상위로 대상을 고르면 미래 정보.** `minute_history` 는 날짜별 대금 상위 200 + 다음 날 → 대상은 **전날 기준**으로 고른다(주도주 차트 모양·카페 검증에서 부풀었던 사례).
- **`kang_minute`** = 장중 +15%↑ 종목·일 전부 → 상한가·급등주 시험은 쏠림 없이 가능.
- 장중 기관 가집계(ka10063)는 약 500종목·첫 발표 09:50 무렵, 프로그램(ka90004)은 2026-10-26 부터만 쌓음 → 과거 1년 검증 불가, 가상 장부로 쌓는다.
- 네이버 테마는 지금 목록 → 과거에 없던 테마가 섞인다(근사).

## 3. 매도 규칙 (모든 백테스트 같게)
- 익절가 닿으면 그 가격(시가가 이미 넘었으면 시가), **손절가 닿으면 즉시**(같은 봉이면 손절 먼저), 둘 다 아니면 **다음 날 09:00 시가**.
- **종가·다음 날 종가 매도 금지.** 지정가 체결 봉은 그 봉 안에서 익절하지 않는다(순서를 모름).
- 비용 0.25% (ETF 0.05%). 체결은 신호 봉 다음 봉 시가 또는 실제 거래된 가격, 호가 1~2칸 미끄러짐 시험.

## 4. 평가
- 승률이 아니라 **합계 손익·건당 기대값·손익비·최대 낙폭·기간별 합**으로 본다.
- **★ = 앞 반·뒤 반 모두 + 이고 가장 좋은 5일을 빼도 +** (`Report.stats`).
- 조건을 여러 개 나눠 보고 고른 값은 우연일 수 있다 → 가상 장부로 20~30건 쌓은 뒤 판단, 그 전 튜닝 제안 금지.
- 계좌 단위로 다시 본다: 단독으로 좋은 매매도 같은 계좌에선 다른 매매의 현금을 뺏어 나빠질 수 있다(전황·테마 대장 거르기 사례).

## 5. 엄밀성 체크리스트 (결과 보고 전)
1. 자료 칸 NULL·0, 수정주가 섞임, 9-14 전후 기준 확인
2. 체결 가능성 (상한가 잠김 중 매수, 프리장 08:50 종료, NXT 거래 여부)
3. 미래 정보 (그날 순위·종가·마감 수급을 장중 판단에 쓰지 않았나)
4. 책·일지 사례 재현 (규칙이 원래 사례를 잡나)
5. 코드 검토 (같은 봉 손절 먼저, 다음 날 가격 기준)

## 6. '전과 같은 결과' 확인 (구조를 바꿀 때)
- 백테스트: 바꾸기 전·후 같은 날짜로 돌려 매매 목록(날짜·종목·수익률)을 파일로 비교 (`cmp`).
- 장중 실행: `screener.duckdb` 의 `rank_snapshots`(매분 대금 순위)·`investor_intraday`·`program_intraday` + 일봉 DB `minute_ohlcv` 로
  그날을 매분 다시 돌려(가짜 시세) 신호·가상 매매·잔고 비교. 실행기 전체는 `SCREENER_DB_PATH`=복사본, `KIWOOM_REAL_TRADING=off`, `--no-paper --no-telegram`.
