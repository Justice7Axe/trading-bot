## 1. 리스크 관리 (가장 일관된 부분)
- 트레이드당 약 0.5%, 추세 확실(JPY 크로스 등) 시 1%. 손실 금액이 매번 거의 같음 = 규율의 증거.
- 손익비 최소 2. 승률 37~41%인 달도 수익. "승률은 의미 없다".
- 최대 드로다운 2~2.5% 목표, 3% 손실 시 리스크 축소. 손절 자리 재진입은 리스크 절반. 복수 매매 금지.
- 매매 횟수 적게 (2024-02: 월 5회). 매매 많아지면 심리 문제 신호.
- 수익 구간에서만 포지션 추가. TP1 후 본전 손절, 이후 트레일링.
- 월 목표 없음. 실제 월 수익 약 2.5~4% (20만 달러 프랍 계좌).
- 확신 시 같은 방향 상관 페어 중복 진입 허용 (손실도 커짐을 인정).

## 2. 금 데이트레이딩 (인터뷰)
- NFP: 발표 직전 15분봉 고/저 표시 → buy stop + sell stop → 체결 방향 최소 10포인트. 발표 시 보통 15~20포인트 움직임. 미리 그은 15분 범위로 발표 직후 꼬리·과도한 체결가 회피. 슬리피지는 주로 TP에서. (최근 3회 NFP는 변동성 약했다고 인정)
- 세션 시작이 최대 변동성. 방향 없는 세션은 쉬고 변동성·거래량 있는 세션으로 이동.
- 강한 상승장: 도쿄 개장 ATH 돌파 → 리테스트 롱.
- 주말 뉴스 갭은 월요일에 메워짐 → 되돌림 레벨 진입.
- 박스권은 손익비가 안 나와 매매 금지.

## 3. 외환 스윙 (2024)
- 펀더멘털로 리스크온/오프 판단 → 리스크온: AUD/NZD/JPY 크로스 롱, 리스크오프: CHF(안전자산) 강세 → AUD/CHF, GBP/CHF 숏.
- "극단 페어": 성격이 반대인 통화끼리 (AUD/CAD 등). USD 페어 회피(조작·뉴스 많음), 대신 USD 연동 CAD 사용.
- 셋업: 추세선 돌파 + 1시간봉 50/200 MA 크로스 + 피보 38.2/61.8 리테스트. 상승 채널 하단 반등, 삼각수렴 돌파 후 38.2 리테스트. 목표는 채널 상단.
- 박스권 성향 페어(AUD/NZD, EUR/GBP)는 손절을 61.8 바로 위가 아니라 더 넓게.

## 4. BTC/알트 (2024-11 영상 + 인터뷰)
- 레벨 단위 매매. 여러 번 거부된 저항대에서 롱 금지. ATH 돌파 → 강세 반응 → 리테스트 후 롱.
- 상승 추세에서 숏 금지. 고점이 더 이상 높아지지 않으면 하락 추세(제시 리버모어). 헤드앤숄더에서 숏 추가.
- BTC가 알트의 기준. RSI 다이버전스로 전환 확인.
- "스마트 DCA" = 과열 구간 분할 익절 + 일봉 50/200 데드크로스 시 대부분 정리.

## 5. 밈코인 (인터뷰)
- 통계 봇으로 승률 높은 KOL 선별 → 텔레그램 CA를 Trojan/GMGN으로 자동 매수. 스나이퍼 많은 토큰 제외. (본인도 KOL이 팔로워에게 덤핑한다고 인정)
