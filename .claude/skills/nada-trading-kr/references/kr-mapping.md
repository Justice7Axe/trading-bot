# Nada 기법 → 한국 주식 변환표

## 1. 그대로 적용
리스크 0.5~1%, 손익비 ≥ 2(비용 차감), 드로다운 규칙, 적은 매매, 월 목표 없음, 변동성 없는 종목 단타 금지.

사이징 예: 계좌 3,000만 원 × 0.5% = 15만 원. 진입 10,000 / 손절 9,700 → 손절폭 300원 + 비용(수수료·거래세·슬리피지) 약 32원 = 주당 약 332원 → **451주(451만 원)**. 비용을 빼고 300원으로만 나누면 500주가 나오지만 그러면 실제 손실이 한도를 넘는다.
목표 10,600 이면 비용 차감 손익비 1:1.70 → 보류. 1:2 를 맞추려면 목표 **10,700 이상**(호가 단위 반올림).

## 3. 리스크온/오프 판단 (한국판)
- 리스크온 신호: 원/달러 하락(원화 강세), 나스닥·필라델피아 반도체지수 상승, 외국인 현물·선물 순매수.
  → 고베타 주도 테마(반도체, 코스닥 성장주)에 집중.
- 리스크오프 신호: 원/달러 급등, 미 증시 급락, 외국인 선물 대량 순매도, 지정학 뉴스.
  → 현금 비중 확대, 방어주, 인버스(사용자가 원할 때).
- "극단 페어" 교훈 → 단타는 변동성·거래대금 큰 주도주에서만. 안 움직이는 종목(AUD/NZD 같은)은 제외.

## 4. 버릴 것
- KOL 콜 추종 → 국내 리딩방·종목추천 추종. 선행매매·불법 리딩방 위험. 권하지 않음.
