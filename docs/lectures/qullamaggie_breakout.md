## 2. 영상 요지

1. **이미 많이 오른 종목만 봄.** 최근 1·3·6달 상승률 상위 1~2%이면서 그 사이 30~100% 넘게 오른 적이 있는 종목. 이런 종목은 '20~50% 오르고 쉬고 다시 오르는' 계단을 만든다는 관점임.
2. **쉬는 구간이 좁아질 때까지 기다렸다가 윗선을 뚫는 순간 삼.** 쉬는 구간(2주~2달) 동안 저점이 높아지고 폭이 좁아지며 10·20일선 위에 붙어 가야 함. 사는 날은 장 시작 1·5·60분 고점을 뚫을 때 삼. 손절은 그날 저가이고, 손절폭이 그 종목의 하루 평균 움직임보다 크면 사지 않음.
3. **작게 지고 크게 이기게 수량을 맞추고, 나눠 팖.** 손절에 닿으면 계좌의 0.25~1%만 잃게 수량을 정하되 한 종목은 계좌의 10~20%(많아야 30%)까지. 3~5일 뒤 3분의 1~절반을 팔고 남은 물량 손절선을 산 값으로 올림. 나머지는 종가가 10일선 아래로 마감하는 날 전부 팖. 승률은 25~30%뿐이고, 시장이 무너질 때는 쉬어야 한다고 영상이 거듭 말함.

| 그날 매수 기준 | 장 시작 처음 몇 분(1분·5분·길게는 60분)에 생긴 고점을 뚫으면 매수 |
| 거래량 | 돌파하는 날 평소보다 크게 터지는 경우가 많음 (필수 조건으로는 말하지 않음) |
| 손절선 | 산 날의 저가 |
| 손절폭 거르기 | 손절폭이 그 종목의 하루 평균 움직임보다 크면 안 삼 (예: 하루 평균 5%, 손절폭 8% → 안 삼) |
| 1회 위험 | 손절선에 닿으면 계좌의 0.25~1%만 잃게 수량을 맞춤 |
| 한 종목 금액 | 보통 계좌의 10~20%, 많아야 30% (위험 공식이 한도를 넘으면 한도만큼) |
| 일부 매도 | 산 뒤 3~5일이 지나면 3분의 1~절반 (예시 둘은 절반, 테슬라 5거래일째·줌 4거래일째) |
| 남은 물량 손절 | 일부 매도 뒤 손절선을 산 값(본전)으로 올림 |
| 나머지 매도 | 종가가 10일선 아래로 마감하는 날 전부. 더 길게는 20일선, 처음 하는 사람은 10일선 |
| 보유 기간 | 며칠~몇 주, 잘 풀리면 몇 달 (정해진 기간 없음) |
| 시장 분위기 | 시장 전체가 무너질 때는 돌파가 잘 안 통하니 쉼. 나쁠 때 덜 하고 좋을 때 크게 |
| 승률 (영상 주장) | 25~30%. 이길 때는 처음 건 위험의 10배·20배 넘는 움직임이 흔하다고 함 |

### 3-2. 영상에 없는 것 → 우리가 정해야 함

'영상에 없음 — 우리가 정해야 함'인 칸은 선택지만 적음. 어느 것을 쓸지는 사용자가 정함.

| 번호 | 항목 | 영상 | 선택지 |
|---|---|---|---|
| ① | 상위 1~2%를 어디서 셀지 | 미국 전체 종목 | 영상에 없음 — 우리가 정해야 함. A 일봉 DB 전체 주식(2,674종목, ETF·ETN·우선주·스팩·상장 20거래일 안 뺌)에서 1·3·6달(21·63·126거래일) 상승률 각각 상위 2% ≈ 각 50종목, 셋 중 하나라도 들면 후보 / B 상위 1%(각 약 27종목)로 좁힘 / C 셋 다 아니고 3달만 |
| ② | '30~100% 넘게 오른 적'의 뜻 | 기간 안에 30% 넘게 오른 적 | 영상에 없음 — 우리가 정해야 함. A 앱 예 그대로: 3달(63거래일) 상승률 ≥ 30% / B 최근 126거래일 안에서 '어느 저점 → 그 뒤 고점'이 +30% 이상인 구간이 있음(계단 한 칸을 직접 찾음) |
| ③ | 쉬는 구간 찾기 | 2주~2달, 저점 ↑, 폭 ↓, 10·20일선 위 | 영상에 없음 — 우리가 정해야 함. 예: 최근 10~40거래일 중 '구간 시작 = 그 안 최고가 날'로 잡고 ⓐ 구간 앞 절반 최저가 < 뒤 절반 최저가(저점 높아짐) ⓑ 뒤 절반 (고가−저가)/종가 폭 < 앞 절반 폭(📈 켈 수축 돌파의 '직전 10봉 폭 < 그 앞 10봉 폭'과 같은 꼴) ⓒ 구간 모든 날 종가 ≥ 20일선, 마지막 날 종가와 10일선 차이 ±N% 안. ⓒ의 N, 구간 길이를 몇 개로 볼지가 숫자로 남음 |
| ④ | 윗선 값 | 쉬는 구간 고점 | 영상에 없음 — 우리가 정해야 함. A 구간 정규장 고가의 최고값(예시 그림의 점선) / B 구간 종가 최고값(꼬리 뺌, 선이 조금 낮아짐) |
| ⑤ | 장 시작 고점 몇 분 | 1분·5분·60분 셋 다 말함 | 영상에 없음 — 우리가 정해야 함. A 5분(09:00~09:04 고가) / B 1분 / C 60분(09:00~09:59) / D 둘을 같이: 장 시작 5분 고점과 쉬는 구간 윗선 중 **높은 값**을 넘으면 삼 (영상 그림은 두 선을 따로 설명해서, 둘의 관계를 영상이 정하지 않음) |
| ⑥ | 매수 가능 시간 | 없음 | 영상에 없음 — 우리가 정해야 함. A 09:05(⑤의 고점이 정해진 뒤)~15:19 / B 장 초만(~10:00, 장 초 고점 돌파의 뜻에 가장 가까움) / C 15:15~15:19 종가 근처 한 번(📈 켈 일봉 방식) |
| ⑦ | 하루 평균 움직임 계산 | "하루 평균 움직임" | 영상에 없음 — 우리가 정해야 함. A 최근 20거래일 (고가 ÷ 저가 − 1) 평균 % / B 최근 20거래일 (고가 − 저가) ÷ 종가 평균 / C 🐢 터틀 돌파의 N(진짜 폭 20일 평균)을 %로 |
| ⑧ | '그날 저가' | 산 날의 저가 | 영상에 없음 — 우리가 정해야 함. A 매수하는 순간까지의 오늘 정규장 저가(그 순간 확정된 값, 장중에 바로 판정 가능) / B 그날 끝난 뒤 저가 — 장중엔 모르므로 실시간엔 못 씀 |
| ⑨ | 손절폭 상한 | 하루 평균 움직임 이하 | 위 ⑦·⑧로 계산: (매수가 − 오늘 저가) ÷ 매수가 ≤ 하루 평균 움직임이면 삼. 손절폭이 0(지금가 = 오늘 저가, 시가 바로 돌파)일 때 손절선을 어떻게 둘지는 영상에 없음 — 우리가 정해야 함 (예: 최소 −0.5%) |
| ⑩ | 1회 위험 % | 0.25~1% | 영상에 없음 — 범위 중 어느 값을 쓸지 정해야 함. A 1% / B 0.5% / C 0.25% |
| ⑪ | 한 종목 한도 | 10~20%, 많아야 30% | 우리 🧾 매매별 가상 계좌 기본 한도가 '계좌 100만 · 종목당 20만(20%) · 동시 5종목'이라 영상 범위 안에 이미 들어감. A 그대로: 수량 = min(계좌 × 위험% ÷ 손절폭, 20만 원어치) / B 30%(30만)까지 늘림. 숫자로 보면 계좌 100만·위험 1% = 1만 원, 손절폭 2%면 공식 50만 원어치 → 한도 20만 원어치가 걸림. 손절폭 5%↑여야 공식(20만)이 한도 아래로 내려옴 → 우리 계좌 크기에선 거의 늘 한도가 수량을 정함 |
| ⑫ | 일부 매도 시점·양 | 3~5일 뒤, 3분의 1~절반 | 영상에 없음 — 우리가 정해야 함. A 산 날 포함 3거래일째 장 마감 무렵(15:15~15:19) 절반 / B 5거래일째 09:00 절반 / C 3~5거래일 사이 '처음 수익이 난 날' 절반. 그때 손실 중이면 팔지 않을지(본전 올리기만 할지)도 영상에 없음 |
| ⑬ | 본전 손절 판정 | 남은 물량 손절선 = 산 값 | 영상에 없음 — 우리가 정해야 함. A 장중 지금가가 산 값에 닿으면 바로 / B 종가가 산 값 아래면 다음 날 09:00 |
| ⑭ | 10일선 계산·판정 | 종가가 10일선 아래 마감 | 영상에 없음 — 우리가 정해야 함. A 정규장 종가 10일 단순 이동평균, 장 마감 정규장 종가가 그 아래면 다음 날 09:00 매도(7️⃣ 주도주 추세의 20일선 이탈과 같은 방식) / B 15:15~15:19 지금가가 10일선 아래면 그날 매도(종가 무렵, 영상의 '마감하는 날 다 판다'에 더 가까움). 이동평균이 단순인지 지수인지도 영상에 없음 |
| ⑮ | 첫 손절(그날 저가) 판정 | 그날 저가 아래로 내려가면 바로 나옴 | 장중 지금가가 손절선에 닿으면 바로 매도로 읽힘 — 우리 매도 원칙(손절 기준 닿으면 즉시)과 같음 |
| ⑯ | 시장 분위기 | 무너지는 시장에선 쉼 | '무너지는 시장'의 기준은 영상에 없음 — 우리가 정해야 함. A 우리 09:10 시장 판정 뒤·강한 하락장 날 안 삼(📈 켈·🪃 급락 반등과 같은 `regime_gate`) / B A에 더해 하락 흐름 보통 날(약세장)도 안 삼 / C 코스피가 20일선 아래면 쉼. '좋을 때 크게'(크기 키우기)도 숫자는 영상에 없음 |
| ⑰ | 갭 상승으로 시작한 날 | 없음 | 영상에 없음 — 우리가 정해야 함. 시가부터 윗선 위면(갭 돌파) 장 시작 고점 돌파 때 삼 / 안 삼. 영상은 '큰 뉴스로 갭이 뜬 종목'을 별개 전략으로 말하고 이 영상에선 다루지 않음 |
| ⑱ | 거래량 조건 | "터지는 경우가 많다" | 영상은 필수로 말하지 않음. A 안 봄 / B 그 시각까지 오늘 거래량이 평소 같은 시각보다 N배 — N은 영상에 없음 |
| ⑲ | 🧷 산 뒤 관리 R1~R7 | 해당 없음 | 며칠 들고 가는 매매라 대상이 될 수 있음. R1 계획 한 줄은 그대로 쓸 수 있고, R3(−20%)·R6(−20% 추가)은 '그날 저가 손절'이 훨씬 먼저 오므로 닿을 일이 거의 없음. R5(+20·40·60% 나눠 익절)는 영상의 '3~5일 뒤 일부 + 10일선' 매도와 겹쳐 같이 쓸지 정해야 함. R4(20거래일 시간 손절)는 영상에 없음 |

약어 풀이 — ETF: Exchange Traded Fund, 거래소에서 주식처럼 사고파는 지수 펀드 · ETN: Exchange Traded Note, 거래소에 상장된 지수 연동 증권 · R1~R7: 우리 '🧷 산 뒤 관리' 규칙 일곱 가지의 번호

## 4. 우리 매매에 쓸 전략 상세 (영상 규칙을 숫자로)

이름 예: **🏄 쿨라매기 돌파** (영상의 '10일선·20일선을 타고 서핑'에서). 아래 '영상' 표시는 영상에 있는 값, '정해야 함'은 3-2 번호의 선택지에서 고를 값임.

### 4-1. 대상 종목 고르기 (매일 저녁 또는 스캐너 시작 때 한 번)

1. 일봉 DB 전체 주식에서 ETF·ETN·우선주·스팩·상장 20거래일 안 종목을 뺌 (우리 공통 규칙).
2. 1·3·6달 상승률 상위 1~2% (영상, 범위는 ① 정해야 함).
3. 30~100% 넘게 오른 적 (영상, 뜻은 ② 정해야 함).
4. 전 거래일 종가 > 20일선 (영상 앱 예).
5. 쉬는 구간 모양: 저점 높아짐 · 폭 좁아짐 · 10·20일선 위에 붙음, 2주~2달 (영상, 숫자는 ③ 정해야 함).
6. 통과 종목마다 윗선(④), 하루 평균 움직임(⑦), 10일선 값을 계산해 '관심 종목 + 윗선' 목록으로 저장. 영상의 '가격 알림'이 우리에겐 장중 스캐너 감시임.
7. 우리 공통 거르기(전날 외인·기관 둘 다 순매도면 뺌, 🌀 무너지는 국면 종목 뺌, ☕ 카페 종목 안에서만 사는 방침)를 덧붙일지는 영상에 없음 — 우리가 정해야 함.

### 4-2. 매수 조건 (장중)

- 시각: ⑥ 정해야 함 (예: 09:05~15:19).
- 봉: 일봉으로 고른 후보를 장중 지금가로 판정. 1분봉은 필요 없음 — 장 시작 N분 고점은 09:00+N분 시점의 '오늘 고가' 시세 한 번으로 정해짐.
- 조건: 지금가 > 쉬는 구간 윗선 **그리고** 지금가 > 장 시작 N분 고점(⑤) → 매수.
- 거르기: (매수가 − 오늘 저가) ÷ 매수가 > 하루 평균 움직임이면 안 삼 (영상, 계산은 ⑦·⑧ 정해야 함).
- 종목당 하루 한 번, 이미 들고 있으면 다시 안 삼 (영상에 없음 — 우리가 정해야 함).

### 4-3. 수량

- 수량 = min(계좌 × 위험%(⑩) ÷ 손절폭, 한 종목 한도(⑪)) ÷ 매수가, 1주 미만이면 1주 (1주 처리 영상에 없음 — 우리가 정해야 함).
- 영상 예(줌): 계좌 1억, 위험 1%, 손절폭 0.9% → 공식 1억 1천만 원어치 → 한도 30% 3천만 원어치.
- 우리 가상 계좌(100만)에선 ⑪ A면 거의 늘 20만 원어치가 됨.

### 4-4. 손절·익절·매도 시점

| 순서 | 무엇 | 언제 | 근거 |
|---|---|---|---|
| 1 | 손절: 지금가 ≤ 오늘 저가(매수 순간 값) | 장중 바로 (⑮) | 영상 |
| 2 | 일부 매도 3분의 1~절반 | 3~5거래일 뒤 (⑫) | 영상 |
| 3 | 남은 물량 손절선 → 산 값 | 일부 매도 직후, 판정은 ⑬ | 영상 |
| 4 | 나머지 전부 매도: 종가 < 10일선 | 마감 판정 (⑭) | 영상 |
| — | 목표가 익절 | 없음 | 영상 (목표가를 말하지 않음) |
| — | 15:19 정리·보유 기간 제한 | 없음 | 영상 (몇 주~몇 달 들고 감) |

- 일부 매도 전에 10일선 아래로 마감하면 어떻게 할지(바로 전부 팔지, 첫 손절선만 볼지)는 영상에 없음 — 우리가 정해야 함. 테슬라·줌 예시는 둘 다 일부 매도 전에 10일선을 깨지 않았음.

### 4-5. 시장 분위기별 사용 여부

- 영상: 시장 전체가 무너질 때는 쉼, 나쁠 때 덜 하고 좋을 때 크게. 2022년 내리막에서 계좌가 크게 줄었다고 영상이 직접 말함.
- 우리 기준으로 옮기면 ⑯ 선택지. 우리 시장 판정 이름(강한 상승장·상승 흐름 보통·하락 흐름 보통·강한 하락장) 중 어디까지 쉴지, '크게'를 몇 배로 할지는 영상에 없음 — 우리가 정해야 함.
- 약세장 날을 쉬는 쪽(⑯ B)을 고르면 약세장이 이어지는 동안 신호가 거의 없을 수 있음.

약어 풀이 — 없음

## 6. 우리 시스템에서 구현할 때 필요한 자료·모호한 점

**필요한 자료와 있는 곳**
- 1·3·6달 상승률 순위: `data/daily_ohlcv.duckdb` `daily_ohlcv`(2022-01-03~2026-11-13, 마지막 날 2,674종목, 수정주가). 126거래일이면 충분함. 9-14 뒤 종가는 20:00 애프터 종가(통합)라 정규장 종가와 조금 다름 — 순위용으로는 영향이 작지만, 쓸지 정규장 값으로 바꿀지 정해야 함.
- 쉬는 구간 윗선·10·20일선·하루 평균 움직임: 정규장 값이 필요함. 9-14 뒤는 `data/daily_regular.duckdb`(정규장 값)에 있는데 날짜별 대금 상위 약 500~1,200종목만 있음(마지막 날 576종목). 상승률 상위 종목이 여기 없으면 📏 변동성 돌파처럼 그 종목만 키움 통합 1분봉으로 정규장 일봉을 만들거나 `data/minute_history.duckdb`를 씀. 📈 켈 일봉이 쓰는 '9-14 전 daily_ohlcv + 9-14 뒤 daily_regular' 이어 붙이기를 그대로 쓸 수 있음.
- 장 시작 N분 고점·오늘 저가·지금가: 장중 스캐너(`screener/run_intraday.py`)가 분마다 받는 KRX 대금 순위 현재가 + 후보만 `market.quote(code, integrated=False)`(오늘 시가·고가·저가) 한 번씩. 09:05 시점 '오늘 고가'가 곧 5분 고점이라 1분봉 조회가 필요 없음. 60분 고점을 고르면 📈 켈 30분 `KellMinuteWatcher` 의 09:00·09:30 봉 자료를 같이 쓸 수 있음.
- 장부: 모의는 `execution/paper.py`(`PaperTrader`), 매매별 가상 계좌는 같은 파일 `AccountTrader`(계좌 100만·종목당 20만·동시 5종목), 공용 가상 장부는 `execution/ledger.py`. 
- 수량 공식에 쓸 계좌 잔액: `AccountTrader` 가 매매별 잔액(시작 100만 + 실현 손익)을 계산함.

**지금 장치로 바로 안 되는 것**
- `ledger.Plan` 은 가격 기준(stop·half_at·target·next_day)만 있음. '3~5거래일 뒤 절반'(시간 기준), '절반 판 뒤 손절선을 산 값으로 올림', '종가 < 10일선이면 매도'를 넣으려면 새 칸이 필요함. paper 쪽은 7️⃣ 주도주 추세의 '추세' 방식(20일선 이탈 → 다음 날 09:00)과 `_sell_half`(절반 매도)가 있어, 이동평균 일수를 10으로 바꾼 새 방식 하나 + 날짜 기준 절반 매도를 붙이는 꼴이 됨.
- 손절선 = 매수 순간 오늘 저가 → 매수 때 `paper_trades.stop` 에 적어 두면 재시작해도 남음(📈 켈과 같은 방법). 본전으로 올릴 때 같은 칸을 고침.
- 1·3·6달 상승률 순위는 지금 어느 스캐너에도 없음 → 스캐너 시작 때(또는 20:00 일일 작업 뒤) 한 번 계산하는 새 계산이 필요함.

**모호한 점 (영상만으로 정할 수 없음)**
1. 쉬는 구간 '저점 높아짐·폭 좁아짐·선 위에 붙음'을 숫자로 어떻게 판정할지 (3-2 ③). 영상은 눈으로 보는 모양으로만 설명함.
2. 쉬는 구간 윗선과 장 시작 N분 고점이 둘 다 나올 때 둘의 관계 (3-2 ⑤ D) — 영상은 두 그림을 따로 보여 줌.
3. 장 시작 고점이 1·5·60분 중 무엇인지 (3-2 ⑤).
4. 일부 매도 날짜와 양 — '3~5일', '3분의 1~절반'으로 범위만 있음 (3-2 ⑫).
5. 10일선 이탈을 종가로 볼지, 장 마감 무렵 지금가로 볼지, 다음 날 시가에 팔지 (3-2 ⑭).
6. '무너지는 시장'과 '좋은 시장'의 기준 (3-2 ⑯).
7. 갭으로 윗선을 넘어 시작한 날의 처리 (3-2 ⑰).
8. 수정주가(일봉)와 원가격(장중 시세)이 섞이면 액면분할·무상증자 종목의 윗선·10일선이 틀어짐 → 그런 종목은 그날 빼는 것이 안전함 (우리 백테스트 공통 주의 사항과 같음).
9. 상한가(+30%) 근처 돌파는 체결이 어려움.

**실행 단계 (가상 → 모의)**
1. **가상 장부만**: 매일 저녁 후보·윗선 목록을 만들고, 장중엔 신호만 🧾 매매별 가상 계좌(주문 없음)에 기록. 영상이 권한 '사지 말고 10번 지켜보기'(선을 뚫은 날·3~5일 뒤 가격·10일선을 깬 날)를 매매일지 📓 에 그대로 적음. 일지 이름표 '🏄 쿨라매기 돌파'.
2. **키움 모의 계좌**: 가상 장부 기록이 쌓이고 사용자가 정하면, 같은 규칙으로 모의 매수(종목당 금액·보유 한도는 모의 기본 또는 사용자 지정).
3. 실전은 이 문서 범위 밖 (사용자 결정 사항).

기존 자료 사정 때문에 정한 것:
- **상승률 순위는 `daily_ohlcv` 종가로 셈.** 9-14 뒤 `daily_ohlcv` 종가는 20:00 애프터 종가(통합)인데, 정규장 값(`daily_regular`)은 날마다 대금 상위 약 500~1,200종목만 있어 전 종목 순위를 낼 수 없음. 순위 다음 단계(63일 +30%·20일선·쉬는 구간·ADR20·10일선)는 모두 정규장 일봉으로 계산함.
- **정규장 일봉 빈 날은 🐢 터틀 돌파와 같은 방법으로 채움** (`TurtleContext`를 그대로 씀): 9-14 전 `daily_ohlcv` + 9-14 뒤 `daily_regular`, 빠진 날은 `minute_history.duckdb` → 파일 캐시(`data/qulla_regular_fill.json`, 🐢 캐시도 읽음) → 키움 통합 1분봉 09:00~15:30 순서. 상승률 상위 종목은 작은 종목이 많아 빈 날이 많음 → 스캐너가 매 확인 때 30번씩 채우고, 다 채운 종목부터 대상이 됨. 전날 대비 ±31% 넘게 튄 날(수정주가 섞임 의심)이 있으면 그날 뺌.
- **강한 하락장 판정이 09:10 에 나므로 판정 전(09:05~09:10)에는 기다림.** 그사이 기준을 넘은 종목은 판정 뒤 첫 확인 때 아직 위에 있으면 삼.
- 판 날에는 같은 종목을 다시 사지 않음.
