## 1. 한 줄 요약
매수 신호·매도 규칙은 그대로 두고, 그날·이번 주 손실이 커지거나 손실 낸 종목을 다시 살 때 모의 매수 금액을 절반으로 줄임.

## 2. 종목 고르기
- 없음 (종목 선정은 다른 매매가 함). 원래 Nada 셋업(장 시작 5·15분 고점 돌파, VI 풀린 뒤 돌파, 전고점 돌파 눌림)은 쓰지 않음

## 3. 사는 자리
- 없음 (금액만 조정)
- 그날 손익 −2% 이하 또는 이번 주(월요일부터) 손익 −3% 이하 → 이후 매수 금액 절반
- 오늘 손실로 끝난 종목을 다시 사면 → 금액 절반. 두 조건이 겹치면 1/4. 1주가 그보다 비싸면 1주
- 줄인 이유는 매수 알림의 📏 줄과 `paper_trades.note` 에 남음
- 예외: 7️⃣ 주도주 추세·📍 중심선·🪜 애프터 정배열은 정한 금액 그대로 (`paper.py` 575줄)

## 4. 파는 자리 (익절·손절·시간)
- 없음 (각 매매 원래 규칙)

## 5. 시장 상황별 쓰임
