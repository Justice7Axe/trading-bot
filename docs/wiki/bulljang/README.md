## 1. 한 줄 요약
이평선(SMA 25·50·200)과 거래량 가중 이평선(VWMA100)을 기준으로 밟고 오를 때 사는 코인 선물 단타 채널임. 국내 주식에 그대로 옮긴 세 기법은 손실이라 접었고, 무너지는 종목 거르기(🌀)와 급락 반등(🪃)만 씀.

## 2. 종목 고르기
- 🌀 A 무너지는 국면(매수 제외): 120일 안 고가가 그 앞 250일 최저가의 2배↑, 종가 < 고가 × 0.7, 50일선 내려가는 중, 종가 < 50일선 < VWMA100
- 🌀 B 바닥: 최근 120일 중 A 인 날 ≥ 60, 최근 40일 폭 ≤ 25%·거래량 2배↑ 날 2번↑, 50일선·VWMA100 가까움, 최근 3일 종가 > VWMA100. 선별: 전날 대금 100억↑·100위 안, 최근 5일 외인+기관 순매수, 전날 둘 다 순매도면 뺌
- 🪃 장중 누적 대금 30위 안, 시총 2,000억↑, 전날 외인·기관 둘 다 순매도 뺌, 프로그램 순매수 줄지 않음, 같은 테마 2종목↑ 대금 100위 안

## 3. 사는 자리
- 🌀 B: 마지막 날 저가가 VWMA100 을 밟고(×1.01 안) 종가가 그 위 → 다음 날 09:10~09:30 모의 매수
- 🪃: 1분봉 VWMA100 아래로 급락(−4%·30봉) 뒤 투매 거래대금, 다음 봉이 저가를 안 깨면 절반 → VWMA100 되찾거나 반등 고점 돌파 때 나머지 절반 (09:10~14:30)

## 4. 파는 자리 (익절·손절·시간)
- 🌀 B: 전 거래일 종가 < VWMA100 이면 09:00 매도. 손절·익절·15:19 정리 없음 (영상에 없어 사용자에게 보낸 예시 그대로)
- 🪃: 급락 저점 −0.5% 닿으면 손절 · 급락 시작 전 20봉 최고가(첫 매물대)에 닿으면 30% 익절 · 남은 물량은 1분봉 5개 연속 VWAP 아래 마감이면 매도 · 15:15 전부 정리(밤 안 넘김). 숫자는 영상 설명을 사용자와 정한 가정값
