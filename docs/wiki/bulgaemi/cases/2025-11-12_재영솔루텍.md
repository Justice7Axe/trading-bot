## 2. 피할 자리 — 첫날 윗꼬리 거래량
- 급등이 처음 시작된 날(11-05)을 가리키며 "이런 구간에서는 살 수 없다"고 함
- 이유: **첫날 윗꼬리에서 거래량이 터지면 조심해야 함** → 경계하고 실제로 사지 않음

## 3. 햄버거 판정 — 샤넬·에르메스 비유
- 원칙: **같은 환경끼리 비교함**. 전날 거래가 터졌으면 오늘은 그보다 더 큰 돈이 들어와야 오름
  - 어제(거래 터진 날)가 '샤넬' 자리면 오늘은 더 비싼 '에르메스' 자리 → 돈을 더 내야 오름
  - 거래가 마른 날 다음이면 가볍게 올라갈 수 있음
  - 음성으로는 "11월 11일이 거래가 말랐다(300억도 안 됨)"고 했으나 일봉상 11-11은 약 1,130억이 터진 날임 → 거래 마른 날은 11-10을 말한 것으로 봄
- 기준 봉 (11-11 1분봉): 36억, 크게 오를 때 아랫꼬리 달린 39억, 28억 → 머리 큰 봉이라 정확하진 않지만 **30억 후반대가 넘을 기준**
- 11-12 오전 10시대 급등: 1분봉이 **약 30억밖에 안 터짐 → 햄버거 약함 → 안 함**
  - 실제로 10:05쯤·10:40쯤 두 번 약 1,720에서 막힘(동그라미 두 개) → 11:30까지 약 1,620으로 밀림
  - "오전에 어디서 샀어도 손절했을 것" → 이런 자리를 피하는 것만으로 수업료를 크게 아낀다고 강조함

## 4. 사는 자리 — 긴 시간으로 매물 소화 뒤 돌파
- 핵심: **"햄버거가 조금 부족해도 긴 시간을 주면 매물을 소화한 것"** (전날 영상에서 한 말을 다시 짚음)
- 11:00~13:50 약 3시간 동안 1,620→1,720 사이로 천천히 올라옴 (화면에 수평선)
- **13:55쯤 1,720 고점을 뚫고 빨간 선(약 1,788)을 돌파하는 자리**에 동그라미 → "여기서 사면 된다, 쫙 올라간다"
  - 빨간 선은 전날 종가 대비 +20% 선으로 보임 (1,490 × 1.2 = 1,788, 숫자를 맞춰 본 추정)
- 결과: 14:24 고가 1,922 → 돌파 자리(약 1,760~1,790)에서 약 +7~9%, 종가 1,835로 버팀

2. **매물 소화**: 오전 햄버거는 약했지만 3시간 다지면서 매물을 받아냄
3. **프로그램**: 매도가 10억~20억도 없었고 조금씩 매수가 들어온 것으로 기억한다고 함
4. **뉴스(작은 트리거)**: 09:11부터 "3분기 영업이익 전년 대비 198% 급증, 하이브리드 OIS 성장 본격화" 기사가 이어짐, 10:04 "+9.33% 52주 신고가" 기사 → "기술적 요건이 맞을 때 작은 호재 하나라도 있으면 매우 유리함"
