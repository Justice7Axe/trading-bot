## 1. 한 줄 요약
재료·수급·차트를 함께 보고, 급등한 종목을 추격하지 않고 1분봉 이동평균선(10분선·20분선·480분선)까지 눌릴 때 사는 단타임. 1분봉 기법은 거의 다 손실이라 쓰지 않음.

## 2. 종목 고르기
- 판단 = **재료 + 수급 + 차트**. 보조지표 없이 캔들·이동평균선·거래량만
- 시초가 **+10%↑ 갭** 종목, 전날 상한가 종목, 전날 또는 그날 **+15%↑** 종목(CK480)
- **강한 테마 = 09:00~09:10 에 세 종목↑ +10%↑**. 대장 +10%↑ 일 때 2등 +7%↑·3등 +5%↑ 여야 시세 유지
- 골드존: 시총 10조↑ 대형주 + 섹터 강세 + 장 초부터 프로그램 매수
- 장 초 시초가를 강하게 깨는 종목은 그날 제외, 역배열 종목 매수 금지

## 3. 사는 자리
- 책의 '5·10·20·240·480분선' = **1분봉 차트의 5·10·20·240·480개 이동평균선** (240분선 ≈ 하루, 480분선 ≈ 이틀)

| 기법 | 사는 자리 |
|---|---|
| 시초가 +10%↑ 갭 | 시초가 매수 금지. 음봉 2~3개 뒤 09:08 무렵 **10분선 터치** |
| 상한가 다음 날 | 09:03~05 눌림 1차, 09:26 뒤 이평 수렴 2차 |
| 20분선 회복 / 골드존 | 20분선을 깬 뒤 5~20분 안에 다시 넘음 |
| **CK480** (직장인용) | +15%↑ 종목이 1분봉 480분선까지 내려와 지지 + 5~20분 옆걸음, 14:30 전 |
| 전일 고가 돌파 박스 | 장대양봉이 전일 고가 돌파 → 약 10분 옆걸음 → 그 고점 돌파 |
| 종가 베팅 | 14:30 뒤 기관·외인 순매수 + 일봉 고가 갱신 / 도지 / 바닥권 240·480일선 거래량 돌파 |
| 일봉 스윙 | 급등 뒤 20일선 눌림 3회 분할, 신고가 돌파 뒤 5일선 타고 보유 |

- 시간: 09:00~09:30 테마주 골든타임, **10:00 뒤 새로 사지 않음**, 10:00~14:30 쉼, 14:30~15:30 오후 매매·종가 베팅
- 종가 베팅 전 나스닥 선물 −1%↓ 면 안 함

## 4. 파는 자리 (익절·손절·시간)
- 숫자 있는 손절은 셋뿐: **CK480 480분선 이탈 −2% 이내**, 60분선 이탈 −2% 이내, 직장인 −10% 자동 손절
- 10분선 확실 이탈 손절(갭 눌림), 시초가 라인 이탈 즉시 손절(상한가 다음 날), 초강세 종목은 5분선 안 깨면 보유·첫 10분선 이탈 매도
- CK480 12시 뒤는 +1~3% 익절, 240분선 저항이면 매도
- 일봉: 급등주 5일선·중간 10일선·완만 20일선 이탈 매도, 240일선 이탈 무조건 손절, 스윙 눌림은 +10%↑면 실현
- 하루 목표 원금 3% 안팎, 닿으면 그날 끝. 물타기·복수 매매 금지

## 5. 시장 상황별 쓰임
- 상승장: 스윙 70% · 단타 30% 계좌 분리. 시장이 나쁘면 현금 50%↑, 지수가 급락하면 쉼
- 7월 말~8월 말은 매매를 줄임, 주말·연휴 전 현금화
- 우리 검증에서 남은 건 **강한 상승장 날(코스피 09:10 ≥ +1σ) 09:10~09:20 갭 +10~15% 10분선 터치**뿐 — 31일 표본·앞 기간 손실이라 확정 안 됨

## 8. 쓸 때 주의
- 책 주장 확인: '+10% 갭의 90%는 장 초 눌림'은 맞음(93%), '열에 아홉은 시초가가 고점'은 39~48%, '09:04 봉이 시초가 못 넘으면 99% 하락'은 실제 80%
- 1분봉 검증 함정 두 가지 (다른 매매 검증에도 해당)
  - 1분봉 저장 자료는 대금 상위만 있어 실패한 갭 종목이 빠짐 → 넣으면 시초가 매수가 크게 나빠짐
  - 상한가 근처(+28.5%↑) 매수를 체결로 치면 결과가 부풂 (줄 서 있어 실제로는 못 삼)
- 1분봉은 원가격, 일봉은 수정주가라 섞으면 액면분할 날 가짜 손실이 남 (LS ELECTRIC 사례)
- 일봉 후보 둘(바닥권 240일선 돌파 종가 베팅, 250일 신고가+정배열+거래량 2배)은 6️⃣ 주도주 신고가·🌙 종가 재돌파와 겹침
- 프로그램 매수·호가 잔량·뉴스·시간외 단일가 자료가 없어 골드존·프로그램 기법은 책 조건을 다 못 갖춤
