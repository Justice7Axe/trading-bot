## 4. 저장 규칙
- **모든 매매전략은 이 위키에 둠** (2026-11-17 사용자 '모아줘'). 전략 규칙·상태(실전·모의·중단)를 바꾸면 스킬과 해당 위키 페이지(`playbook.md`, `<매매법>/README.md`)를 같은 PR 에서 함께 고침. 새 매매법을 만들면 `docs/wiki/<매매법>/` 폴더와 `README.md` 를 만들고 위 표에 한 줄 넣음. 접으면 `retired.md` 에 한 줄 옮겨 적음.
- **매매법마다 폴더 하나** (2026-11-17 사용자): `docs/wiki/<매매법>/README.md` = 규칙·상태·결정 기록, 그 매매법의 종목 사례·복기·영상 분석이 생기면 같은 폴더 `cases/YYYY-MM-DD_종목명.md` 에 쌓고 README 사례 목록에 한 줄 넣음 (불개미 폴더와 같은 틀).
- **종목 매매 관점을 분석하면 항상 저장함** (2026-11-17 사용자). 트레이더마다 폴더 하나: `docs/wiki/<트레이더>/README.md`(공통 원칙·사례 목록) + `cases/YYYY-MM-DD_종목명.md`. 날짜는 영상 파일 이름보다 화면 속 차트 날짜를 따름.
- 문서 문체는 "임·됨·함", 매매 번호·이모지 옆에는 항상 매매 이름, 페이지 끝에 약어 풀이.
- 비밀값(토큰·쿠키·계좌번호)은 적지 않음 (공개 저장소).
