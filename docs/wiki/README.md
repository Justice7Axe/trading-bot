# 매매 지식 위키

트레이더 영상·강의에서 뽑은 **종목별 매매 관점 분석**을 모아 두는 곳임. 매매 전략을 정하거나 종목을 판단할 때 언제든 꺼내 씀.

| 폴더 | 트레이더 | 내용 | 스킬 |
|---|---|---|---|
| [bulgaemi/](bulgaemi/README.md) | 불개미 트레이드 | 공통 원칙 + 종목 사례 | `bulgaemi` |

## 저장 규칙
- 종목 매매 관점을 분석하면 **항상** 이 위키에 저장함 (2026-11-17 사용자 요청)
- 트레이더마다 폴더 하나: `docs/wiki/<트레이더>/README.md`(공통 원칙·사례 목록) + `cases/YYYY-MM-DD_종목명.md`
- 날짜는 영상 파일 이름보다 화면 속 차트 날짜를 따름
- 새 사례를 넣을 때 그 트레이더 README의 사례 목록과 공통 원칙을 함께 고침
