## 3. 사는 자리
- 통합 1분봉을 전날 08:00~20:00 + 오늘 봉까지 이어 붙여 종가 60·120봉 단순 평균
- GC(골든크로스): 60선이 120선 아래 → 위, 종가 > 120선
- ALN(정배열 우상향): 60선 > 120선, 두 선 모두 10봉 전보다 높음, 종가 > 60선
- 09:30~10:40 봉에서 처음 맞으면 종목당 하루 한 번 시장가 (신호가 +1% 넘게 오르면 추격 안 함)

약어 풀이
- AL: 키움 통합 시세(KRX + NXT)
- ETF: Exchange Traded Fund, 거래소에서 사고파는 지수 펀드
- ETN: Exchange Traded Note, 거래소에 상장된 지수 연동 증권
- USDT: 테더, 1달러에 맞춘 코인
- GC: Golden Cross, 짧은 선이 긴 선을 아래에서 위로 넘음
- ALN: Align, 정배열 우상향(60선 > 120선, 두 선 모두 오름)
- Nada: Nada 손실 관리(그날 −2%·주간 −3% 면 금액 절반)
- UTC: 세계 표준시 (한국 시각 −9시간)
- NXT: Nextrade, 넥스트레이드 대체거래소
