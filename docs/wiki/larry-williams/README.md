## 1. 한 줄 요약
오늘 시가 + 어제 정규장 (고가 − 저가) × 0.5 를 넘는 순간 사고, 오늘 시가 아래로 내려오면 손절, 아니면 다음 날 09:00 시가에 다 팖.

## 2. 종목 고르기
- 📈 켈 수축 돌파와 같은 선별(테마 조건만 뺌): 지금 대금 100억↑ & 주식 대금 100위 안 (ETF·ETN·우선주·스팩 뺌)
- 전날 외인·기관 둘 다 순매도 뺌, 상장 20거래일 안 뺌, 🌀 프랙탈 무너지는 국면 뺌

## 3. 사는 자리
- 기준선 = 오늘 09:00 정규장 시가 + (어제 정규장 고가 − 저가) × 0.5. 어제 값은 `daily_regular`, 없으면 1분봉으로 만듦
- 09:00~15:19, 분마다 보는 현재가가 기준선 이상이 되는 첫 확인에 매수, 종목당 하루 한 번
- 기준선보다 1% 넘게 위에서 처음 보거나, 이미 닿았다 내려왔으면 안 삼. 기준선 ≥ 상한가·어제 폭 0 이면 안 삼
- 금액: 종목당 100만 원, 보유 10종목 한도 (Nada 금액 줄이기 적용)

## 4. 파는 자리 (익절·손절·시간)
- 손절: 현재가가 그날 시가 아래로 내려오면 바로 매도
- 익절 없음, 15:19 정리 없음 → 다음 날 09:00 시가 전량

## 5. 시장 상황별 쓰임
- 모든 날 삼 (09:10 판정 전·강한 하락장·하락 흐름 보통 날 포함, 사용자 선택 4A)

## 6. 결정 기록
- 2026-11-13 · 사용자 '1B 2A 3B 4A' · 종목 = 공통 선별, 매수 = 09:00~15:19 언제든, 손절 = 그날 시가 이탈, 시장 = 모든 날. 모의만, 백테스트 안 함
- 이름 '📏 변동성 돌파'는 정리 문서 제안(어제 폭을 자로 재서 선을 긋는다는 뜻)

## 7. 실제 매매 결과
- 🟢 모의: 11-16 AP위성 −7.0%(−68,957원), 11-17 2건 1승 −40,886원(대덕전자 −6.6% 포함) → 3건 1승 합계 −109,843원
- 🟣 잔고 밖 가상: 11-17 1건 −48,555원
- 손절이 '시가 아래'인데 실제 손실이 −6~−7% — 기준선 자체가 시가에서 멀어 산 값과 손절선 간격이 큼

## 8. 쓸 때 주의
- 영상 원래 규칙은 손절 없음이고, 시가 이탈 손절은 우리가 고른 변형임
- 원래 대회는 선물 한 종목이었고, 주식 종목 고르는 법은 영상에 없음. 대회 수익을 이 공식 하나 덕분으로 볼 근거도 없음
- 폭이 큰 종목은 기준선이 이미 많이 오른 자리라, 손절선(시가)까지 거리가 큼
- 9-14 뒤 `daily_ohlcv` 는 08:00~20:00 통합 값이라 폭 계산에 쓰지 않음
