## 1. 한 줄 요약
해외 단타 고수 넷의 기법(VWAP 눌림·투매 반등·개장 5분 범위·오더플로우·다이버전스)을 한국 주식·선물 규칙으로 바꾸고 1분봉으로 시험하는 도구였으나, 우리 표본에서는 우위가 없어 매매에 쓰지 않음.

## 2. 종목 고르기
- 한국 주식: 전날 대금 상위 200 (그날 상위를 섞으면 결과가 부풂), 통합(AL) 1분봉 09:00~15:19
- 선물: 나스닥 선물(NQ·MNQ), 코스피200 선물(K200F)

## 3. 사는 자리
| 전략 | 트레이더 | 자리 |
|---|---|---|
| S1 재료주 VWAP 추세 눌림 | 브라이트스타인 | 재료로 오른 종목이 VWAP 까지 눌렸다 다시 오를 때 |
| S2 투매 뒤 V자 오른쪽 | 브라이트스타인 | 크게 투매한 뒤 반등이 확인될 때 |
| S3 개장 5분 방향 + 패턴 돌파 | 딩웨이펑 | 장 시작 5분 방향으로 박스·W바닥 등 패턴이 완성될 때 |
| F1 경매이론 오더플로우 | 발렌티니 | 1분봉 근사 (선물) |
| F2 MACD·RSI 다이버전스 + 피보나치 | 트룰라스 빌라 | 코드 검증용 (선물) |
- 공통: 09:00~09:15·15:05 뒤 새 진입 금지, 트레이드당 0.5%, 하루 3패 중단, 롱만

## 8. 쓸 때 주의
- 스킬은 백테스트 도구임. 합격 기준 통과 전엔 실전을 권하지 않음
- [S] 트레이더 출처 규칙은 바꾸지 않고, [A] 구현 가정만 학습 구간에서 조정함. 합성 데이터 결과로 수익을 말하지 않음
- 재료·VI·매수/매도 체결량 칸이 없어 근사함
- 사용자가 백테스트 근거를 싫어함(2026-11-10). 다시 쓸 땐 사용자가 직접 요청할 때만

약어 풀이
- VWAP: Volume Weighted Average Price, 당일 거래량 가중 평균가
- AL: 키움 통합 시세(KRX + NXT)
- NQ·MNQ: 나스닥100 선물·그 소형 선물
- K200F: 코스피200 선물
- MACD: Moving Average Convergence Divergence, 두 이동평균 차이로 추세를 보는 지표
- RSI: Relative Strength Index, 과매수·과매도 지표
- S·A: 스킬 표시. S = 트레이더 출처 규칙, A = 구현 가정
- VI: Volatility Interruption, 변동성 완화 장치
- KRX: 한국거래소
- NXT: Nextrade, 넥스트레이드 대체거래소
