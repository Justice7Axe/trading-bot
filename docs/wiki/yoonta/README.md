## 1. 한 줄 요약
09:00~10:00 딱 1시간, 전날 거래대금 큰 주도 테마 종목 3~5개를 미리 골라 일봉 저항 돌파(저돌) 같은 자리에서 사고 +1% 익절·−2% 손절로 짧게 끊는 단타임. 책 그대로는 손실이라 쓰지 않음.

## 2. 종목 고르기
- **장전 3~5종목**을 미리 고름. 장중에 찾으면서 매매하지 않음
- **전날 거래대금 100억↑ + 거래량 1,000만 주↑** (거래량만 보면 동전주가 올라옴)
- 제외: 관리·투자경고·거래정지·단기과열·ETF·우선주·자본잠식
- **주도 테마**: 거래대금 상위 20~30 중 같은 업종·이슈 3종목↑. 주도 테마가 안 보이면 쉼
- **쌍쌍바**: 테마 대장주(상승률 1위)가 +5%↑·거래량 급증·호재 뉴스면 아직 +1~2% 인 2등주를 바로 삼
- 하락장(지수가 이전 저점을 깸): 강한 테마만. 정치 인물주·금리·전쟁·원자재·질병 테마

## 3. 사는 자리
| 타점 | 내용 |
|---|---|
| **저돌 (저항 돌파)** | 일봉 몸통이 강한 저항선을 확실히 뚫음 → 9~10시 뚫는 순간 시장가. 책: "10번 중 9번은 저돌로 진입" |
| 지지저항 | 지지선 근처 분할 매수(50 → 확인 뒤 50), 가장 기본 |
| 변비타점 | 분봉 15선~20선 사이에 좁게 뭉치고 20선이 지지 |
| 시가 | 시가 아래에서 놀다 시가를 돌파하려 하면 매수 준비 |
| 분돌 | 당일 분봉 고점 돌파 (재료가 셀 때만) |
| 10시 이후 2차 상승 | 9~10시 급등 종목이 거래량 유지하며 옆걸음, 5·10분봉 저점 안 깨고 다시 오름 |
| 종가배팅 (보충) | 장 마감 30분~1시간 전, **김보선(3분봉 120선) 지지 + 거래량 감소** → 다음 날 시가 매도 |
- 이평선은 4·15·20·120만 씀. 장 시작 직후 추격 금지, 점심(12~13시) 새 진입 안 함
- 막시무스(5분봉 디마크 High 선 위)로 '오늘 올라갈 힘' 확인

## 4. 파는 자리 (익절·손절·시간)
- 책 기본 자동 주문: **+1% 전량 익절, −2% 손절**
- 123 매도법: +1·+2·+3% 에 나눠 팜
- 4턴4꺾: 4선 위에서 가던 캔들이 4선 아래로 떨어지면 전량 매도
- 반반이: 저항점(또는 +5%↑)에서 절반, 나머지는 4선 이탈까지
- 손절: 기대수익의 절반을 넘으면 손절(+1% 노렸으면 −0.5%), 김보선(3분봉 120선) 이탈
- 하루 규칙: **2번 연속 손절이면 그날 매매 끝**, 단타 = 당일 매수·매도(오버나잇은 예외), 수익금 인출

## 5. 시장 상황별 쓰임
- 상승장(지수 +1%↑ 날): 가장 강한 주도 테마의 대장주 위주, 분할 매수
- 하락·횡보장: 가벼운 사이드 테마(정치·저출산 등)의 대장주, 무거운 메인 섹터(반도체·조선·2차전지)는 피함. 맞는 종목 없으면 안 함
- 우리 시장 분위기 판정과 연결한 운영은 없음

## 8. 쓸 때 주의
- **책 기본 매도(+1%/−2%)는 모든 타점에서 손실** — 이기는 횟수는 많아도 손실 한 번이 이익 세 번을 지움
- 쓸 만한 조각은 저돌 · 주도 테마 장전 3~5종목 · 길게 두는 매도(4턴4꺾·반반이·김보선) · 종가배팅 김보선 정도임
- 저돌은 3️⃣ 막힌 고점 돌파·6️⃣ 주도주 신고가와 같은 종목이 많음 → 같은 종목이면 기존 매매 쪽 매도가 나음
- 종가배팅 김보선만 기존 매매(🌙 종가 재돌파·🧭 디앤서 종가 체크리스트·4️⃣ 역행 강세 종가)와 거의 안 겹치지만, 가장 좋은 5일을 빼면 본전 → 쓰려면 다시 확인 필요
- 뉴스·재료 세기, 호가 잔량, 관리·경고 지정 이력, VI 실제 발동, 미국 지수·동시호가 예상가는 자료가 없어 못 넣음
