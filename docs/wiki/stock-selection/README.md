## 3. 65기법 (B안 + 주도 섹터, 확정 2026-10-12)

- **고르기** (일봉, 장 마감 뒤): 연속 6개 일봉 안 장대양봉(고가/전일 종가 ≥ +15%·양봉·대금 1,000억↑) 상승률 합 ≥ 65% (시총 10조↑ 대형주는 13%·3개↑·합 50%↑), 신호일 고가 ÷ 5거래일 전 종가 ≥ +33%, 시총 5,000억↑, **주도 섹터**(업종 대금 비중 5일 ≥ 5% & 업종 안 장대양봉 비율 10일 ≥ 10%).
- **사기·팔기 (B안)**: 1차 장대양봉 종가 지정가 (신호 다음 날부터 20거래일 안 체결) → 익절 +25% / 1차 장대양봉 시가 이탈 손절 / 최대 5거래일. ⭐ = 신호일 회전율 ≥ 30%.
- **지금**: 20:00 텔레그램 리포트만 (🆕 오늘 포착 / ⏳ 매수 대기 / 📌 보유 중 / ✅ 오늘 청산). 실전·모의 주문 없음.
- 접은 것: % 손절, 5일 체결창, A안(3분할 매수), C안, 급등 4일 이내 거르기 → [retired.md](../retired.md).
- 코드: `analysis/indicators/sixty_five_*.py`, `strategies/sixty_five/`.

## 4. 주도주 스크리너 (조건 ①~⑥) — ⏹ 지금 꺼짐

필수 ①②⑥ + 선택 ③④⑤ 중 2개↑.
- ① 관심: 조회 순위 20위 또는 대금 순위 50위 안
- ② 대금 500억↑(KRX) · +3%↑ · 진폭 6%↑ 또는 ATR14 4%↑
- ③ 테마 동반 ④ 재료 연속성(최근 3일 중 2일 대금 50위·고가권 마감) ⑤ 250일 고가 97%↑ 또는 60일 고가 돌파
- ⑥ 눌림·돌파 시나리오 (손절폭 1.5~8%, 목표 = 위험 × 2)

한계: 여섯 조건을 다 봐야 해서 늦음 (두산테스나 10-13 은 18:46 에야 포착) → 조기 발굴을 붙였지만 그것도 매수로 이어지지 않아 함께 껐음.

## 8. 🧱 저항 재시험 후보 — 지투지바이오형 (✅ 켜짐)

- 일봉 장 마감 기준 (그날 대금 50억↑): H = 60~4거래일 전 고가 최고. ① 최근 5일 +15%↑ 장대양봉 ② 최근 3일 평균 대금 ≥ 이전 20일 × 2 ③ 종가가 H 의 −15~0% ④ 최근 3일 고가 ≥ H × 0.97 → 다음 날 돌파선 R = max(H, 최근 3일 고가).
- 모양만으로는 우위가 없어 후보 목록으로만 쓰고, 실제 매수는 **2️⃣ 저항 돌파**(시총 2천억↑ & 돌파 때 누적 대금 ≥ 평소 하루 대금)가 함.

## 10. 종목 고르기 연구에서 배운 것 (짧게)

- **1분봉 차트 모양** (10-17): 사용자 주도주 9종목 모양을 규칙으로 옮겨도, 전날 대금 상위만 써서 바로잡으면 우위가 거의 없음. ⚠️ `minute_history` 는 그날 상위 종목이 섞여 있어 반드시 **전날 대금 상위만** 써야 함.
- **시가 전 정보** (10-18): 대형주 시가→종가를 가르는 시가 전 특징 29개 모두 무력. 갈림은 **당일 외인·기관 수급** — 그래서 장중 잠정치·프로그램 순매수를 쌓는 중 (잠정 외인 방향은 마감 값도 70% 정도만 맞음, 프로그램 순매수가 외인 대용으로 더 나음).
- **상승 직전 찾기** (10-31): 지표를 묶은 모델은 '오를 종목'이 아니라 '출렁일 종목'·'대형주 베타'를 고름. 장중 수급이 쌓인 뒤 다시 봄.
- **조회 급증** (10-30): 조회 20위 진입은 끝물 → 매수 근거로 쓰지 않고, 쓴다면 매도·과열 쪽.
- **10-26 강세 종목 포착 복기**: 14종목 중 10종목을 포착했지만, 포착 순간 사는 것은 강한 상승장 말고는 손실 → 포착을 매수로 잇지 않음 (특히 약세장).
- 뉴스 API 가 키움 REST 에 없음 → 테마 이름은 네이버 업종·테마(`data/naver_groups.duckdb`, 매일 12:00)로 붙임.
