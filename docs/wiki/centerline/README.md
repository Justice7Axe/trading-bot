## 1. 한 줄 요약
최근 10거래일 안에 대금 10위 안으로 크게 오른 장대양봉(기준봉)의 몸통 가운데 가격(중심선)을, 1분봉이 대금 터지며 강하게 뚫고 올라가면 사는 매매임.

## 2. 종목 고르기
- 기준봉: 전 거래일까지 **10거래일 안**, 양봉, **+10%↑**, 거래량 20일 평균 **3배**↑, 대금 **100억**↑.
- 그날 **대금 10위 안**, **시총 5천억↑**, 우선주 제외 (`live.py` `TOP_N = 10`, `MIN_MCAP = 5e11`).
- 기준봉 뒤 이미 📍 신호가 난 종목은 뺌.
- 중심선 C = 기준봉 정규장(KRX 1분봉) (시가 + 종가) / 2.

## 3. 사는 자리
- 09:01~15:00 매분, 막 끝난 KRX 1분봉이 **직전 봉 종가 < C ≤ 이 봉 종가**.
- 그 봉 대금 ≥ **10억** & ≥ 직전 20봉 평균 × **5** → 모의 시장가.
- 전용 몫 **300만**, 종목당 **50만**. 보유 한도 칸은 안 씀, 몫을 넘으면 잔고 밖 가상 매매.

## 4. 파는 자리 (익절·손절·시간)
- 익절 **+3%**.
- 손절 **C × 0.99** (중심선 −1%).
- 둘 다 아니면 **다음 날 09:00**.

## 5. 시장 상황별 쓰임
- 09:10 판정 전 체결도 삼(시험 그대로).
- **09:10 강한 하락장 판정 뒤엔 안 삼** — 시험에서 강한 하락장 날만 크게 손실(25건 승률 12%).
- 약세장·지수 20일선 아래 날은 오히려 괜찮았음(매수 전에 아는 지수 정보로는 하락장을 못 거름).

## 8. 쓸 때 주의
- 기준봉 +10% 기본형은 산 종목 60~75% 가 종가로 중심선을 다시 깸 — 강한 종목은 안 내려오고 내려오는 종목이 약함(절반 눌림 매수의 공통 함정).
- 수익이 큰 몇 건에 몰리는 추세형(중앙값 손실, 승률 25%) → 몇 주 손실이 이어져도 이상한 일 아님.
- 5일씩 묶이면 다른 매매(6️⃣ 주도주 신고가·📕 상한가 풀림)의 현금을 줄여 계좌 합계는 거의 그대로였음.
- 신호가 드묾 — 기준봉 조건(대금 10위·시총 5천억)이 좁음.
- 모든 모의 매수 공통으로 카페 종목 목록(`common/cafe_universe.py`) 안 종목만 삼.
